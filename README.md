# 🎓 Educational Platform

A clean and scalable educational platform built using **React.js**, **Vite**, and **CSS3**.  
The app includes reusable components, intuitive design, and performance-focused architecture.

## 🔗 Live Demo

👉 [View the platform online](https://engabdullahaljamal.github.io/Educational-platform/)

## 🚀 Features

- ⚛️ Built with React and Vite
- 🧱 Component-based structure for easy scalability
- 🎯 Clean and maintainable codebase
- 🌐 Responsive design with pure CSS
- 🖱️ Smooth user interaction and navigation

## 🛠 Tech Stack

- React.js  
- Vite  
- CSS3  
- JavaScript  
- HTML5

## 📁 Project Structure

- `public/`: Static assets  
- `src/components/`: Reusable UI components (Header, Footer, Sliders, Cards...)  
- `App.jsx`, `main.jsx`: Entry point and app root  
- `index.css`, `App.css`: Global styles  
- `index.html`: Root HTML file  
- `vite.config.js`: Vite configuration
